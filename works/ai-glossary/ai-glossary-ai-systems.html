AI Glossary
Beginner Field Notes

AI 系统名词速查

从模型调用到安全护栏，快速听懂 AI 应用开发里的高频术语。

Model API Key Memory Real-time Copilot
0006
Core Access
01 / Access Layer

调用 AI 能力的入口

先选模型，再用密钥访问服务，让模型按需调用外部函数。

01

Model模型

经过训练后能处理输入并生成结果的 AI 系统核心。

不同模型擅长的任务、速度、成本和能力边界都不一样。
02

API Key接口密钥

访问 API 服务时用来证明身份和权限的一串密钥。

它像账号密码一样敏感，不能写进公开代码或截图里。
03

Function Calling函数调用

让模型按预设格式请求调用某个函数，再由程序执行并返回结果。

适合查订单、算价格、改日程这类需要确定动作的任务。
0106
Knowledge Recall
02 / Retrieval Layer

让 AI 记住并找回信息

记忆保存偏好，向量库组织语义，搜索按含义而不是只按关键词。

04

Memory记忆

AI 系统保存并复用用户偏好、历史信息或任务状态的能力。

记忆让体验更连续，但也需要清楚边界和隐私规则。
05

Vector Database向量数据库

专门存储和检索向量的数据库，常用于相似度搜索和 RAG。

它不是按字面完全匹配，而是按“内容像不像”来找。
06

Semantic Search语义搜索

根据问题的含义寻找相关内容，而不是只匹配一模一样的关键词。

用户问法变了，只要意思相近，也能找到相关资料。
0206
Modality
03 / Conversion Layer

把图像和声音变成可处理内容

文字识别、语音识别和语音合成，是多模态产品的常见入口。

07

OCR文字识别

Optical Character Recognition，把图片、截图或扫描件里的文字识别出来。

发票识别、证件录入、截图转文字都常用 OCR。
08

Speech-to-Text语音转文字

把人说的话转成文本，方便搜索、总结、翻译或交给模型继续处理。

会议纪要、语音输入、客服录音分析都离不开它。
09

TTS文字转语音

Text-to-Speech，把文本转换成自然语音输出。

AI 客服、有声内容、语音助手都常用 TTS。
0306
Performance
04 / Runtime Layer

让 AI 应用又快又稳

实时体验靠低延迟，缓存减少重复计算，限速保护系统资源。

10

Real-time实时

系统能在很短时间内响应输入，让用户感觉像同步对话或即时互动。

实时语音、实时字幕、实时协作都很看重延迟。
11

Cache缓存

把常用或刚算过的结果临时保存起来，下次直接复用。

缓存能提速、降成本，但也要注意内容过期。
12

Rate Limit速率限制

限制单位时间内能发起多少请求，用来保护服务稳定和控制成本。

超过限制时，系统通常会返回“太频繁”或要求稍后再试。
0406
Control Layer
05 / Safety Layer

让 AI 更可控地协助人

护栏限制风险，人类保留关键判断，副驾驶负责辅助而不是替代。

13

Guardrails护栏

限制 AI 行为边界的规则、检测和拦截机制，用来降低风险输出。

比如拒绝敏感请求、校验格式、过滤危险内容。
14

Human in the Loop人在回路中

在 AI 流程中保留人工审核、确认或接管，让关键决策不完全自动化。

常用于医疗、金融、客服升级和高风险操作。
15

Copilot副驾驶

嵌在工作流程里的 AI 助手，帮助人写作、编码、分析或操作软件。

它不是自动驾驶，而是坐在旁边帮你提速和补位。
0506
