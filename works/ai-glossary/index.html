AI Glossary
Beginner Field Notes

AI 基础名词速查

从 LLM 到涌现，快速听懂 AI 领域的基础概念和行业黑话。

LLM Token Prompt Agent RAG
0006
Language Input
01 / Input Layer

模型如何读懂一句话

先把语言拆成片段，再用指令驱动生成。

01

LLM大语言模型

通过大量文本学习语言规律，能理解、生成和改写内容的 AI 模型。

把它想成一个会预测下一段文字的通用语言引擎。
02

Token词元

模型处理文本的最小单位，可能是一个字、一个词的一部分或标点。

计费、速度、上下文长度，很多时候都按 token 来算。
03

Prompt提示词

你给模型的输入指令，告诉它要做什么、按什么标准输出。

好 prompt = 目标清楚 + 背景足够 + 格式明确。
0106
Context Design
02 / Context Layer

把有效信息放进窗口

模型不是全知，它只看得到当前给它的材料。

04

Prompt Engineering提示词工程

设计、测试和优化提示词的方法，让模型更稳定地产出想要的结果。

像给一个聪明实习生写任务单：目标、边界、验收都要清楚。
05

Context上下文

模型当前能看到的全部信息，包括问题、历史对话、文件片段和工具结果。

没放进上下文的资料，模型通常不会自动知道。
06

Context Window上下文窗口

一次推理里最多能容纳的上下文总长度。

窗口越大，可参考材料越多，但仍要筛重点、排顺序。
0206
External Ability
03 / Extension Layer

让模型接上外部能力

工具、协议和智能体，把模型从会回答扩展到会执行。

07

Tool工具

模型可以调用的外部能力，比如搜索、读文件、运行代码或查数据库。

让模型从“只会回答”变成“可以执行”。
08

MCP模型上下文协议

Model Context Protocol，用统一方式把 AI 应用连接到工具和数据源。

可以把不同系统包装成同一种“插口”。
09

Agent智能体

能围绕目标规划步骤、调用工具、观察结果并继续行动的 AI 系统。

重点不是只回答，而是能把任务往前推。
0306
Action System
04 / Action Layer

从回答到执行

能力可以被包装成流程，输出也需要被校验。

10

Skill技能包

一组可复用的任务说明、脚本和资源，帮助模型按特定流程完成工作。

像给 Agent 装上一个专业工作包。
11

API应用接口

Application Programming Interface，软件之间互相调用能力的接口。

AI 产品常用 API 把模型能力接进自己的应用。
12

幻觉Hallucination

模型把不确定或不存在的信息，说得像真的一样。

事实核验、引用来源和工具查询，都是降低幻觉的常用办法。
0406
Knowledge Layer
05 / Knowledge Layer

从检索到能力跃迁

把知识找回来，把相似度算出来，把复杂能力看出来。

13

涌现Emergence

当模型规模和训练量达到某个阶段，突然表现出原本不明显的能力。

像很多简单规律叠加后，出现了新的整体能力。
14

Embedding向量表示

把文字、图片等内容转换成向量，让机器能计算相似度。

搜索、推荐、RAG 检索，很多都靠它打底。
15

RAG检索增强生成

先从外部知识库检索资料，再交给模型生成答案的方法。

相当于给模型一场“开卷考试”，尤其适合最新或私有资料。
0506
